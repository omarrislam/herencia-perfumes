# 00 — Project Overview

**HERENCIA** — premium heritage perfume brand e-commerce web app.

- **Tagline:** "Luxury in every drop."
- **Market:** Egypt. **Currency:** EGP.
- **Audience:** mostly mobile shoppers; premium fragrance buyers.
- **Launch catalog:** 3–4 perfumes + curated bundles.

## Goals

1. Lightweight but rich, premium-feeling storefront.
2. Full admin dashboard controlling everything on the site.
3. Excellent SEO + performance (Lighthouse ≥ 90 mobile).
4. Engaging, tasteful animations without hurting performance.
5. Strict brand fidelity to the identity in `/identity`.

## Stack

- **Frontend:** Vite + React + TypeScript, Tailwind CSS, Framer Motion.
- **Backend:** Node + Express + TypeScript.
- **DB:** MongoDB (Mongoose).
- **Shared:** TS types + Zod schemas in `packages/shared`.
- **Images:** Cloudinary. **Hosting:** single VPS + Nginx + PM2.
